# Talk to Guruji — website rebuild

A rebuild of talktoguruji.com: the same content with a new design and a working consultation platform. It covers chat, voice and video with astrologers, plus a wallet, free kundli tools, puja booking, Astro Mart, an astrologer dashboard and an admin panel.

## Quick start

Requires Node.js 20.11 or later.

```bash
cd web
npm install
npm run setup
npm run dev
```

Open http://localhost:3000. Demo logins, commands and architecture notes are in [CLAUDE.md](CLAUDE.md) and [web/README.md](web/README.md).

> Private client project. Do not make this repository public.
